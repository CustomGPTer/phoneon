Better than changing your screen timeout

You can make the screen stay on longer by changing Android's own Screen timeout setting, then remembering to change it back. PhoneOn does it for as long as you choose and puts everything back by itself. This page shows only the rows where PhoneOn does more.

What PhoneOn does not do

PhoneOn does not stop the power button turning the screen off and locking the phone. It needs "Display over other apps" to work. It is not on Google Play, so it does not update itself.

Where the setting does more

The screen timeout setting needs no app and no permission, and it applies all the time without you starting anything.

Phones change. If a row is no longer right, open an issue on GitHub and it will be corrected.
